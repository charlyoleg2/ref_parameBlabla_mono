desiBlabla-uis
==============


Presentation
------------

*desiBlabla-uis* is the static web-server of the web-app *desiBlabla-ui*.


Requirements
------------

- [node](https://nodejs.org) > 20.10.0
- [npm](https://docs.npmjs.com/cli) > 10.1.0


Installation
------------

```bash
npm i -D desiBlabla-uis
```


Usage
-----

```bash
npx desiBlabla-uis
npx desiBlabla-uis --help
```


Usage without installation
--------------------------

```bash
npx desiBlabla-uis
npx --package=desiBlabla-uis desiBlabla-uis
npx --package=desiBlabla-uis desiBlabla-uis --help
```


Development
-----------

```bash
git clone https://github.com/MYNAME/ref_parameBlabla_mono
cd ref_parameBlabla_mono
npm install
npm run ci
npm -w desiBlabla-uis run run
```
