desiBlabla-ui
=============


Presentation
------------

*desiBlabla-ui* is a *SvelteKit* application for presenting the designs of *desiBlabla*.
This web-app can be served as github-page and/or via the static-web-server *desiBlabla-uis*.


Requirements
------------

- [node](https://nodejs.org) > 20.10.0
- [npm](https://docs.npmjs.com/cli) > 10.5.0


Development
-----------

```bash
git clone https://github.com/MYNAME/ref_parameBlabla_mono
cd ref_parameBlabla_mono
npm install
npm run ci
npm run preview
```
