desiBlabla-cli
==============


Presentation
------------

*desiBlabla-cli* is a *command line interface* application for presenting the designs of *desiBlabla*.


Requirements
------------

- [node](https://nodejs.org) > 20.10.0
- [npm](https://docs.npmjs.com/cli) > 10.1.0


Installation
------------

```bash
npm i -D desiBlabla-cli
```


Usage
-----

```bash
npx desiBlabla-cli
npx desiBlabla-cli --help
```


Development
-----------

```bash
git clone https://github.com/MYNAME/ref_parameBlabla_mono
cd ref_parameBlabla_mono
npm install
npm run ci
npm -w desiBlabla-cli run run
```
