DesiBlabla
==========


Presentation
------------

*DesiBlabla* is a *design library* based on [parametrix](https://charlyoleg2.github.io/parametrix/).

It contains the some 3D-shapes.

Getting started
---------------

```bash
git clone https://github.com/MYNAME/ref_parameBlabla_mono
cd ref_parameBlabla_mono
npm -w desiBlabla install
npm -w desiBlabla run ci
```

Dependencies
------------

*DesiBlabla* runtime depends only on *Geometrix*. Use *desiBlabla-ui* WebUI or *desiBlabla-cli* CLI to visualize and export the designs in different formats like dxf, svg, gltf, stl, brep, step and others.
